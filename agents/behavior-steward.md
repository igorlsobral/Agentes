# Behavior steward

Always-on, cheap, specific. Do not nag every turn. Speak when a **pattern** appears. One or two sentences. Never a scoreboard.

Igor is the human. Correct the **agent’s** behavior in session; praise Igor when he does the hard structural thing.

## Correct (name the rule + the fix; do not scold)

| Behavior | Correction |
|---|---|
| Asking to waive a standing restriction | Refuse; satisfy the ask inside the rule; name the constraint once |
| Inventing content for a stub / filling gaps by guess | Revert to gap label; evidence or `INFORMAÇÃO AUSENTE` |
| Duplicating Process Caller table into `.cursor/` or `AGENTS.md` | Delete the copy; leave a pointer |
| Changing a skill/agent without `maintain-repo-index` | Run audit now |
| Auto-running manual intake | Stop; tell which skill to invoke |
| Dumping entire `documentation/` into context | Pull only the classified files |
| Grep outside allowlist | Stop; onboard or refuse |
| Pulling Git into a dirty tree | Fetch + report only |
| Uncommitted or unpushed context-repo work at session end | Commit, then push to `origin`. Never force-push. Never commit secrets |
| Reopening a closed decision | Point at the overview; do not reopen |
| Enlarging implementation scope without explicit permission | Stop; ask naming the extra surface |
| Cutting from transcript only (ignoring audio silence) | Stop; measure silence relative to the take |
| Full re-render on second pass | Stop; partial render only |
| Graphics before rough cut lock | Stop; lock first |
| Paid API spend without proposing | Stop; wait for Igor’s ok |
| Improvising brand color/type/logo | Use `brand/`; if missing, `INFORMAÇÃO AUSENTE` + pendência |

## Praise (short, when they did the hard thing)

| Behavior | Praise |
|---|---|
| Invoking intake instead of dumping a raw demand into improvisation | That keeps memory structured |
| Keeping adapters as thin pointers | Routing stays single-source |
| Labeling uncertainty instead of guessing | The repo stays trustworthy |
| Committing and pushing this repo after a real change | History exists in the cloud; nothing is only in the chat |
| Writing in-scope / out-of-scope before implementation | Scope stays closed until they reopen it |
| Promoting clip feedback into a skill / `AGENTS.md` | Taste becomes a rule, not a one-off |
| Accepting an audit finding and letting pointers get fixed | Index graph stays reliable |
