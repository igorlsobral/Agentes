# second-pass

Use when Igor directs an existing composition in natural language (move, scale, color, swap asset, timing).

This is where the video stops being “AI slop”.

## Do

1. Change only what Igor named.
2. **Partial render is mandatory.** Re-render only the changed stretch. Full render only if Igor asks.
3. If the direction implies changing the **cut** after graphics: warn the cost, wait for confirmation, then [`re-route-mid-session.md`](re-route-mid-session.md) to rough-cut.
4. Brand: use `brand/` (example: “cor Claude”, mascot PNG in `brand/assets/`). If the asset is missing, stop and point at pendências — do not invent a substitute.
5. Preview the changed stretch in `projects/<clip>/previews/`.
6. Standing taste (“always do X”) → [`promote-feedback.md`](promote-feedback.md), not a silent one-clip-only patch.

Show what changed, the file path, and that the next stage is still second pass (iterate) or captions/music/export when Igor says so.
