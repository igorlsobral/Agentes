# apply-ubiquitous-language

Use when a term is new, overloaded, or disputed (example: “Whisk X” vs WhisperX).

## Do

1. Prefer the glossary: [`documentation/ubiquitous-language/glossary.md`](../documentation/ubiquitous-language/glossary.md).
2. Domain terms are never translated.
3. If Igor used a term and the glossary conflicts, stop and align the glossary — do not silently mix.
4. Add a glossary row only with evidence from Igor or from a file in this repo.
