# re-route-mid-session

Use when the nature of the demand changed (example: second-pass direction becomes “rebuild the EDL”).

## Do

1. Re-read [`agents/process-caller.md`](../agents/process-caller.md). Do not create a second table.
2. Name the old route and the new route in one line each.
3. Load the new skill. Drop files that belong only to the old route.
4. If a rough cut must reopen after graphics: warn cost, wait for confirmation (`video-editor/AGENTS.md`).
